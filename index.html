A two-panel merge and refactor workbench built with HTML5, JavaScript, Bootstrap, Tailwind and FontAwesome, connected to PHP API endpoints.

      Workflow

      1. MERGE

      Paste PR and CODE-BASE into PANEL1, then click MERGE.

      2. FAILURES

      If merge checks fail, PANEL1 displays all failures and REFACTOR appears.

      3. REFACTOR

      Refactored code is moved into PANEL2 with an alert message for review.

      4. RE-MERGE

      User can re-merge from PANEL2, and if needed refactor back into PANEL1.

      Integration Endpoints

      POST api/merge_git_cli.php
      Runs real local Git CLI merge validation in a temporary workspace.
      POST api/merge_github.php
      Backend endpoint scaffold for GitHub merge workflows.
      POST api/merge_gitlab.php
      Backend endpoint scaffold for GitLab merge workflows.
      POST api/refactor_ai.php
      Backend endpoint for AI-assisted refactoring or local fallback.
