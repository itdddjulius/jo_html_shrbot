How it works

1. Prepare

Paste PR code in PANEL1 and the target codebase in PANEL2.

2. Merge

Use MERGE to call the selected backend merge hook.

3. Refactor

If the merge fails, REFACTOR becomes available and sends failures + code to the API.

4. Re-merge

Review output in the opposite panel, then use RE-MERGE until satisfied.
